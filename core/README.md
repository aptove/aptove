# aptove-core

Core library crate for [Aptove](https://github.com/aptove/aptove).

This crate provides the open source core library used by `Aptove` (the OSS binary).

The public API may change between releases without notice.

For documentation, installation, and usage see the main repository: [github.com/aptove/aptove](https://github.com/aptove/aptove).
