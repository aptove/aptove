# Security Policy

## Supported Versions

| Version    | Supported          |
| ---------- | ------------------ |
| >= 1.2.0   | :white_check_mark: |
| < 1.2.0    | :x:                |

## Reporting a Vulnerability

Please e-mail to saltukalakus@gmail.com and allow a week to get back to you.

Responsible disclosures are kept confidential until a patch is released. Please do not share details of the vulnerability publicly until you have received confirmation that it has been fixed.

Anyone who responsibly discloses a valid vulnerability will be recognised in the **Security Hall of Fame** in the project's README.
